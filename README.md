# Interactive Rating Component

A responsive and interactive rating component built as part of a Frontend Mentor challenge.

## 📌 Overview

This project is a simple interactive rating application that allows users to select a rating from 1 to 5 and submit their feedback.

The application displays a thank-you message after the user submits their rating.

The main goal of this project was to practice building responsive user interfaces and improving my frontend development skills.

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices.
- Interactive rating selection (1–5).
- Visual feedback when a rating is selected.
- Thank-you screen after submitting a rating.
- Clean and simple user interface.

## 🛠️ Built With

- HTML5 – For the project structure.
- CSS3 – For styling and responsive layouts.
- JavaScript – For interactive functionality.
- Flexbox – For layout alignment.
- Media Queries – For responsive design.

## 📱 Responsive Design

The application is designed to work across different screen sizes, including:

- Desktop computers
- Tablets
- Mobile phones

## 📚 What I Learned

While building this project, I practiced:

- Creating responsive layouts using CSS.
- Working with Flexbox and CSS Media Queries.
- Handling user interactions with JavaScript.
- Improving my HTML structure and CSS organization.
- Using Git and GitHub to manage and share my projects.

## 🚀 Getting Started

To run this project locally:

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open index.html in your browser.
